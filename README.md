# Animex

Animex is now a Next.js app using the App Router.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates the production build.
- `npm run start` runs the production server after a build.

## Routes

- `/` shows the anime search experience.
- `/signup` shows the sign-up form.
- `/signin` shows the sign-in form.
